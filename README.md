# 808 PIT

Interactive browser soundboard demo from Amienigma Studios.

**Atlanta subs · Memphis stabs**

**Live:** TODO — add Vercel URL after deploy

Playable synth rack with Atlanta 808 subs, Memphis horrorcore chords, waveform, filter, and envelope.

## Stack

React 19 · TanStack Start · Tailwind · Vite · Vercel

```bash
npm install
npm run dev
```

Dev server defaults to `http://localhost:8080`.
